# atari-breakout
Re-creation of the classic Atari Breakout game using an FPGA + Microblaze soft processor. Built to work on any VGA display.

This project was created as my final for my Hardware/Software Co-Design class at SLU.

Made using VHDL and C with a Basys 3 FPGA board.
